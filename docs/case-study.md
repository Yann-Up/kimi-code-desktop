# 用 Kimi Code 排查官方源码,从零做出 Kimi Code 桌面客户端

## 一、案例简要信息

- **案例标题**:用 Kimi Code 排查官方源码,从零做出 Kimi Code Desktop 桌面客户端
- **案例简介**:给 Kimi Code CLI 做了一个 Tauri 桌面壳——对话界面原样内嵌官方 `kimi web`,壳层补上用量统计、桌面通知、托盘、插件管理、皮肤、桌宠、自动更新等桌面能力,后端可跑在本机 / WSL / SSH 远端。整个项目从官方源码 API 排查、架构设计到编码调试,全部由 Kimi Code 完成。
- **项目属性**:个人项目 / 开源项目(MIT)
- **实践类型**:应用开发(桌面应用)
- **作者背景**:Yann, 全栈开发

## 二、工具链与环境

- **AI 工具**:Kimi Code CLI(全程主力,在终端中使用)
- **主力模型**:Kimi Code 默认模型
- **IDE/编辑器**:IntelliJ IDEA(仅作代码查看与提交)
- **语言/框架**:Rust + Tauri v2(后端壳);React 18 + TypeScript + Vite + Tailwind CSS + zustand(前端)
- **运行环境**:Windows

## 三、背景与目标

Kimi Code 有 CLI 和 `kimi web` Web UI,但日常使用存在明显缺口:Web UI 需要开浏览器、手动起服务、看不到用量配额、没有桌面通知,跑长任务必须一直盯着页面。

目标:做一个轻量桌面壳,把官方 Web UI 原样内嵌,壳层补齐桌面应用能力;同时不侵入官方前端,官方升级零影响。

## 四、关键过程

### 1. 前期拆解:让 Kimi Code 先排查官方库

最大的障碍是官方没有公开 `kimi web` 的内部接口文档。第一步不是写代码,而是让 Kimi Code 通读官方 kimi-code 仓库源码:

- 梳理 `kimi web` 的完整 REST 接口(`/api/v1/*`:配额、用量统计、插件管理)与 WebSocket 通知协议;
- 弄清 Bearer token 认证机制、服务启动参数与端口行为;
- 摸清 CLI 数据目录布局与 `KIMI_CODE_HOME` 环境变量解析优先级;
- 确认插件 REST 路由与 TUI `/plugins` 命令的等价关系。

这些排查结论沉淀为壳层的 API 契约(渲染层 ↔ 壳 ↔ 官方服务三段同步),成为整个项目的地基。

### 2. 设计与实现:功能全部由 Kimi Code 编码

基于排查契约,Kimi Code 完成了全部功能的架构设计与代码:

- 集成层:REST 客户端、WS 通知订阅、`kimi web` 进程 spawn 与地址/token 解析;
- 三种后端通道:本机 / WSL / SSH 远端(密码只存系统凭据管理器);
- 桌面能力:用量统计与额度条、桌面通知、系统托盘与关闭确认;
- 插件管理:设置页经 REST 安装/启停/移除,与 TUI 落盘行为一致;
- 增强能力:皮肤立绘、桌宠(透明置顶窗 + WS 事件驱动状态机 + 任务/审批/配额气泡);
- 工程化:CLI 自检/安装/升级、应用自动更新(签名校验 + 双下载源回退)、dev 与正式版完全隔离并存。

### 3. 迭代与调优:疑难问题也交给 Kimi Code

- Tauri 运行期建窗/关窗命令必须 async,否则 WebView2 初始化死锁;
- token 生成时序竞争、`kimi web` 崩溃后的自愈恢复;
- 数据目录残留旧版 CLI 静默遮蔽 PATH 上新版——通过"双候选选新"机制解决;
- 这些排查结论都回写进项目的 AGENTS.md,形成项目级知识沉淀,让后续会话不再踩同一个坑。

## 六、感受、踩坑与建议

1. **没有 API 文档时,让 Kimi Code 先读源码再写代码**。官方库排查这一步做完,后续开发几乎零返工,这是本案例最大的收获。
2. **把排查结论写进 AGENTS.md**。踩过的坑(WebView2 死锁、token 时序、配置目录优先级)沉淀成项目指引后,Kimi Code 每次新会话都自动遵守,复用价值极高。
3. **AI 结对攻克底层坑很快**。桌面框架的死锁、时序类问题,把现象和日志喂给 Kimi Code,定位速度远快于人工翻 issue。
4. **"壳"的思路值得复用**:不改动官方前端、只做增量,既保留官方体验,又与官方升级完全解耦——适用于任何有 Web UI 的 CLI 工具。
5. **建议**:大项目先立"API 契约先行"的约定(渲染层不直接调底层,三处同步),Kimi Code 按约定生成代码,改动可审、可控。

## 七、其他补充

这个项目本身形成了一个闭环:用 Kimi Code 开发 Kimi Code 的桌面壳,从源码排查、架构设计到调试排障,全流程验证了 Kimi Code 处理真实中大型项目的能力。
